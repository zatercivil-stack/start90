# Материалы тестового задания «НОВИЧОК»

Работающая демоверсия: https://tgt.myvelum.com/
Видеодемонстрация (40 секунд): https://tgt.myvelum.com/video.html
Краткий отчёт для HR: HR_REPORT.md (15 строк)
Исходный код и тесты: https://github.com/zatercivil-stack/start90.

Быстрая проверка: README.md → «Проверить за три минуты». После получения доступа репозиторий можно клонировать. Для локального запуска требуется Node.js 22+, затем `npm start`; внешние ключи и сервисы не нужны. Для автоматизированных тестов `npm ci`, `npm test` и `npm run test:e2e` при запущенном сервере и установленном Chromium.

Люди и данные вымышлены. Нет подключения к порталу компании и доказанного влияния на текучесть. Роли в демо переключаются без авторизации; реальные персональные данные вводить не следует.
