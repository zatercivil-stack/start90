# Проверка реализации

Среда: Node.js 22.23.4; Playwright 1.58.2, Chromium headless; Linux. Локальный HTTP-сервер проекта на loopback, не StreamScope.

## Автоматизированные проверки

`npm run check`: синтаксис ES-модулей.
`npm test`: 17 тестов бизнес-логики.
`npm run test:e2e`: 8 браузерных сценариев.

Покрытие доменной логики: корректность seed и связей; границы дат; один запрос на отрицательную проверку; запрет повторной отправки; положительные ответы; обязательность объяснения; будущие проверки; полный цикл с возвратом; запрет закрытия руководителем и чужим новичком; адресат HR; обязательность владельца, срока и действия; исполнители плана; будущий выход; создание шаблона и назначение наставника; объяснимые просрочки; неверные данные; повреждённое хранилище.

Браузерные сценарии:
1. Найти новичка → проверка → новый запрос → руководитель берёт в работу → передаёт решение → новичок подтверждает → обновление страницы → сохранённая история.
2. Прямой запрос → возврат в работу; обращение к HR и ограничение обработки в демороли.
3. Добавление, наставник, пункт плана, поиск и фильтр; HTML в имени показывается текстом.
4. Отрицательная проверка без объяснения, защита от повтора, недоступность будущей точки.
5. Ошибка записи в localStorage: сообщение об ошибке, прежние данные не меняются.
6. Повреждённый JSON не перезаписывается автоматически; сброс только после подтверждения.
7. 390 × 844: отсутствие горизонтального переполнения, отправка и открытие запроса.
8. 1440 × 1000: обзор, инструкция, экспорт JSON, закрытие диалога клавишей Escape.

В первом прогоне 7/8: точное accessible name поля подразделения включало названия option; добавлен явный aria-label. Повторный прогон 8/8. Desktop и mobile скриншоты просмотрены, затем повышен контраст вспомогательных подписей; актуальные скриншоты сохраняет успешный повторный прогон. Критических pageerror в основном сквозном сценарии нет.

## Что не проверено

Нет тестов с реальными сотрудниками и руководителями, данных об удержании, внешнего портала Битрикс24, одновременной многопользовательской работы, серверного хранения, production authentication, реальных мобильных устройств, Safari/Firefox, полноценного аудита WCAG или нагрузочного тестирования. Браузерные тесты проведены на локальном артефакте. Повторно пройдены все 8 сценариев на https://tgt.myvelum.com (11 ноября 2026): 8 passed, 12,4 секунды. HTTP возвращает 308 на HTTPS; HTTPS — 200 с доверенным TLS-сертификатом. Проверка выполнялась браузером на VPS через публичный домен, не с отдельного внешнего устройства.

Демороль и ограничения в доменной логике не являются безопасностью: код и localStorage находятся у пользователя. В production права должны проверяться сервером.

После переработки интерфейса повторно выполнены 17 тестов правил и 8 локальных браузерных сценариев; обзор проверен визуально на ширинах 1440 и 390 px. Публичный домен проверен следующим прогоном.

Публичный релиз с новым дизайном проверен на https://tgt.myvelum.com/: все 8 Playwright-сценариев прошли, 9,2 секунды. Включая мобильный экран 390 px, обновление страницы и полный цикл запроса.
