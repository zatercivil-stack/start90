# Демонстрация для проверяющего

Продолжительность записи: 40,64 секунды (start90-demo.webm). Это запись действующего приложения, без озвучки, с поясняющими титрами. Данные в видео вымышлены.

## Самостоятельный сценарий

- Откройте приложение, перейдите в «Новички», найдите Алексея Ветрова.
- «Посмотреть глазами новичка» → «Проверки» → день 7.
- Ответьте «Да / Нет / Да», укажите отсутствие доступа к ТСД и отправьте.
- Демороль «Руководитель» → «Запросы помощи» → «Нужна помощь · проверка дня 7».
- Напишите первое действие, возьмите в работу. Откройте снова, опишите выданный доступ, передайте на подтверждение.
- Демороль «Новичок» → «Запросы» → откройте запрос → подтвердите решение с комментарием.
- Перезагрузите страницу → «Запросы помощи» → «Решённые»: история сохранена.

Дополнительные проверки: «Проблема осталась» возвращает запрос в работу; адресат HR требует роли HR для обработки; новая карточка без наставника показывает объяснимый сигнал. Через «Как проверить демо» можно выгрузить JSON и сбросить данные с подтверждением.

## Как понимать ограничения

Демороли не являются учётными записями. Все действия происходят в одном браузере. В другом браузере вы увидите независимую демонстрацию. Сайт не подключён к порталу ТГТ и не отправляет реальные сообщения.

Демонстрация: https://tgt.myvelum.com/. Исходники: https://github.com/zatercivil-stack/start90. Статические файлы dist можно разместить на обычном HTTPS-хостинге. Для запуска из репозитория достаточно Node.js и npm start — установка зависимостей нужна только для тестов.
